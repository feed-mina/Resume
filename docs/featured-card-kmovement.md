# A04 · 대표 카드 초안 — KMovement (현재 근거형)

적용 위치: feed-mina.github.io index.html `projects[id="KMovement"]`, Resume/README.md Featured Projects #1.

## 문제

- K-Culture 여행객은 거리보다 "좋아하는 아티스트와 관계가 있는 곳"을 알고 싶어 했다.
- 무거운 영상·음성 생성을 동기 호출로 묶으면 API 전체가 지연된다.
- 다국어 질의에서 지역 조건이 유실되거나 근거 없는 장소가 섞일 수 있다.

## 흐름 (현재 코드 기준)

- 추천·일정 경로: 지역 추출 → 후보의 주소·시도 문자열을 지역 조건과 대조 → 임베딩 검색 → 응답에 sourcePoiCount·poiGrounded로 근거 유무 표시.
- QA 경로(rag_client.py): distance ≤ 0.25인 후보만 컨텍스트에 포함. 별도 chatbot_chain.py 경로는 rerank_score > 0 사용. 세 경로를 한 숫자로 설명하지 않는다.
- 미디어 생성: Celery·Redis 큐로 백그라운드 처리. BLIP-2 분석 결과에 따라 영상 생성 / 3D 패닝 / 뼈대 애니메이션 중 호출 모델을 나눈다.

## 한계 (이력서에 그대로 적는 것)

- 지역 조건 대조는 문자열 기반이며 구조화된 지역코드 동등 비교와 같지 않다. QA·스트리밍 경로에 같은 필터가 있는지 미확인.
- 근거 0건이어도 모델을 호출하는 경로가 있다. 무자료 응답 정책은 A19에서 결정·시험한다.
- 임계값 0.25를 평가셋으로 최적화한 근거 없음. 운영 컬렉션의 metric metadata 미확인.
- MLflow run 수, 비용·메모리 절감 수치는 확인 전까지 적지 않는다.
